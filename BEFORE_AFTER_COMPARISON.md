## New Features

### 1. Time Estimate
```
⏱️ Est. completion: ~2h
```
- Calculates based on voting rate
- Updates in real-time
- Shows in seconds, minutes, or hours

### 2. Last Vote Party Time
```
Last VP: 2026-01-15 14:32
```
- Tracks when last VP completed
- Shows in footer
- Helps track frequency

### 3. Per-Site Contributions
```
🟡 **Minecraft-MP** — 4,377 **(+27)**
```
- Shows how many votes each site added this cycle
- Updates automatically
- Helps identify which sites are most active

### 4. Milestone Markers
```
🟨🟨🟨🟨🟨🟨⬜⬜⬜⬜ 67.2% 50%✓|75%✓
```
- Shows when 50% and 75% milestones are reached
- Visual celebration of progress
- Motivates continued voting
